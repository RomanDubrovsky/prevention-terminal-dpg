Security & Law

Absolute Protection of Children's Data

No leaks. We guarantee compliance with data protection laws and psychologist confidentiality thanks to the "Local Vault" architecture. The terminal operates without transmitting personal data to the internet:

Local Vault (SQLCipher, AES-256)

Names, contacts, and student cards are encrypted and physically stored only on the psychologist's work computer.

State-of-the-art LLMs in Secure Cloud Environment

For generating profiles and case analysis, advanced AI models are used in a protected Secure Cloud Environment (data centers in the EU/US).

Strict Anonymization Before AI

When using the AI assistant, all names and personal identifiers are automatically excluded — only depersonalized methodological context is sent to the model.

Director Sees Numbers, Not Secrets

Management receives aggregated statistics ("15 anxiety requests in class 8B") but has no access to personal data or session records.

Full Offline Mode

Journals and cards are always available, even if the institution temporarily loses internet access.

Personal Data Registry

Personal data is strictly limited to the specialist's local device and is never transferred to external servers.
